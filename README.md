# First\_Skill

开源的 Agent Skill 集合。当前包含一个 Skill：**make-knowledge-cards**。

## 项目解决什么问题

阅读长文章、教程或资料时，信息密度高、重点难抓、读完容易遗忘，而手动整理笔记非常耗时。本项目提供 make-knowledge-cards，让 Agent 自动把文章提炼成 **5\~8 张知识卡片**，帮助快速把握要点、随时复习，把 "读文章" 变成 "留卡片"。

## 主要功能



* **输入灵活**：接受用户粘贴的文章文本，或本地 Markdown / TXT 文件路径

* **输出结构化**：每张卡片包含四个字段 —— 标题、核心知识、简明解释、例子或自测问题

* **数量受控**：典型文章输出 5\~8 张；信息不足时不强行凑数（最少 1 张），上限 8 张

* **质量保证**：只提取真正重要的知识；一张卡片只讲一个知识点；自动删除重复内容；不编造原文没有的信息；输出语言与原文一致

* **边界明确**：不支持网页抓取、PDF、Anki 导出和图形界面

## 安装方法



1. 将 `skills/make-knowledge-cards` 目录复制到你的 Agent Skill 目录（例如 `workspace/.user_skills/`，或对应平台的 skills 根目录）

2. 无需安装任何依赖：Skill 不含脚本，`SKILL.md` 是唯一必需文件，`agents/openai.yaml` 为可选元数据（用于 Agent 界面展示）

3. 复制完成后，向 Agent 提及 skill 名称 `make-knowledge-cards` 即可触发

## 使用方法

向 Agent 说出以下任意一种请求：



* **粘贴文章**：「把下面这篇文章做成知识卡片：`<文章内容>`」

* **本地文件**：「用 make-knowledge-cards 总结这个文件：`C:\notes\article.md`」

Agent 会按「标题、核心知识、简明解释、例子或自测问题」的格式返回 Markdown 卡片。遇到网页链接、PDF 等不支持的输入时，Agent 会说明边界并建议先把内容转成文本。

## 输入输出示例

### 输入



```
\# 少即是多

最近整理房间，扔掉了一半东西，生活反而变轻了。我意识到，我们拥有的大多数物品，其实并没有在为我们服务，而是在占用我们的注意力。

物品需要维护：要擦拭、要收纳、要担心。每一件多余的东西，都是一份持续支出的注意力账单。当家里的东西变少，我发现自己能更快地找到需要的东西，也更容易专注。

同样的道理也适用于信息和日程。减少无意义的通知和聚会，剩下的时间才真正属于自己。

少不是匮乏，而是把资源留给真正重要的事情。断舍离的重点从来不是扔东西，而是想清楚：什么值得留下。
```

### 输出



```
\## 卡片 1：多余的物品是在持续占用注意力

\*\*核心知识\*\*：我们拥有的大多数物品并没有在为我们服务，而是在占用我们的注意力；每一件多余的东西都是一份持续支出的"注意力账单"（要维护、收纳、担心）。

\*\*简明解释\*\*：物品不是免费的：买回来之后，擦拭、收纳、惦记都在不断"收费"，收费单位是注意力。

\*\*例子\*\*：原文实例：作者整理房间扔掉一半东西后，生活反而变轻了。

\## 卡片 2：物品变少，找东西更快、专注更容易

\*\*核心知识\*\*：当家里的东西变少，能更快找到需要的东西，也更容易专注。

\*\*简明解释\*\*：环境越简单，大脑需要处理的信息越少，干扰越少，专注力自然更集中。

\*\*例子\*\*：自测问题：减少物品为什么有助于专注？提示：需要维护和面对的物品少了，注意力支出随之减少。

\## 卡片 3：少的原则同样适用于信息和日程

\*\*核心知识\*\*：少即是多的道理同样适用于信息和日程：减少无意义的通知和聚会，剩下的时间才真正属于自己。

\*\*简明解释\*\*：注意力资源有限，信息过载和日程过满同样是"多余的物品"，同样在占用你。

\*\*例子\*\*：自测问题：除了实物，还有什么可以用"少即是多"来管理？提示：通知、聚会等信息和日程。

\## 卡片 4：断舍离的重点是"想清楚什么值得留下"

\*\*核心知识\*\*：少不是匮乏，而是把资源留给真正重要的事情；断舍离的重点从来不是扔东西，而是想清楚什么值得留下。

\*\*简明解释\*\*："少"是手段，"留对东西"才是目的——先明确什么重要，再决定扔什么。

\*\*例子\*\*：自测问题：断舍离的目标是尽量少地拥有物品吗？答案：不是，是想清楚什么值得留下，把资源留给真正重要的事。
```

> 说明：以上示例为 Skill 的真实测试输出。信息量更大的文章会输出 5~8 张卡片；本文只有 4 个知识点，按规则不凑数。
